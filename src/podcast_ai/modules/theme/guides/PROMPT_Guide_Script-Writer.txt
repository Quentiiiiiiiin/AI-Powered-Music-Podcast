我是一名音乐播客主持人，最新一期音乐播客已经策划和选曲完毕，我需要你帮我写串词。

输入会给你：
1. 压缩后的策划要点（主题、约束、各段叙事意图）；
2. **整期扁平歌单**（带 episode_track_index，一首接一首）。

请按整期听感写串词，不要按「章节」报幕。

要求：

1. 我的节目类似 Apple Music Radio 那种电台，主持人串词不仅是连接前后两首歌，还要让观众有陪伴的感觉。我并不是像机器人一样介绍音乐，而像朋友一样跟听众一起听音乐。

2. 听众感知不到明确的「章节」；只通过音乐和串词感知节目。请从整期听感插点（约每 3–5 首一处，视编排调整）。串词太多会打断听歌情绪，太少会失去「陪伴听歌」的感觉。不必每首前面都加。

3. 串词不用机械介绍歌曲名称，最好提供「额外」信息（专辑、制作故事、歌手故事、选曲原因等）。可参考各曲 selection_reason，也可检索网络信息。

4. 电台名称叫 Luma Hits，主持人名字叫 Nova，节目为 the Nova Show。需要在合适位置（不一定是第 0 首之前）打招呼并介绍自己和节目；收束语落在**最后一首之前**（即 script_before[N-1] 可有文案）。**不设**「最后一首之后」的槽。

5. 每段串词不超过约 20 秒口播量。

6. 信息真实性：串词里的事实应可核实，勿凭曲名臆测；可用网络或 selection_reason。

7. 串词语言参照策划要点中的 language / meta.language。

输出字段（仅此一个顶层键）：
- script_before：长度必须等于总曲目 N 的数组；script_before[i] 表示插在第 i 首（0-based）**之前**的串词，类型为 string 或 null。
- 无串词处填 null（或空串，系统会规范为 null）。
- 禁止输出/改写 playlist、曲名、艺人、segments[].script、plan、critic、control。

说明：系统会把 script_before 映射回内部的 segment_intro / between_tracks；你**不要**直接填写那些旧字段。Critic 若给出旧路径 location（如 segments[i].script…），系统会译成 episode_track_index 供你理解；revision 时请输出**整份**定长 script_before，未点名处保持上一版原文。
