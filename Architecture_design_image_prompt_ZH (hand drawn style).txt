--------------------------------
顺序式 Multi-Agent Pipeline
--------------------------------

按照明确顺序展示：

【Planner Agent 🧠】
↓
【Music Curator Agent 🎵】
↓
【Script Writer Agent 📝】
↓
【Critic Agent ⚠️】

每个 Agent 附带简短说明：

Planner Agent：
• 节目结构规划

Music Curator Agent：
• 歌单生成

Script Writer Agent：
• 主持串词生成

Critic Agent：
• 质量评估

强调每个 Agent：
• 从 Shared State 读取
• 只修改自己负责的字段
• 再写回 Shared State

状态随着迭代不断演化。

每个 Agent 与 Shared State 双向连接：

Agent ↔ Shared State

表示：
持续同步状态。


如果Critic Agent 检测到问题：
• Critic将反馈（Feedback）发送给指定上游agent

必须强调：
• “局部再生成（Partial Regeneration）”
• “只修复问题部分，保持其它内容不变”

使用：
• 循环箭头
• revise
• feedback

如果通过：

【Approved Episode Plan ✅】

内容包含：
• 播放列表
• 主持串词规划
• 章节时间线
• 结构化 JSON 快照
